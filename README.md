# product-3d-ar — سكيل لـClaude بيعمل فيديو منتج ثري دي بالكود

إعلان منتج ثري دي واقعي، 16:9، بعناوين عربية وصوت. ما في كاميرا ولا تصوير ولا برامج مونتاج.

المنتج نفسه مبني بالكود جوّا Blender، قطعة قطعة: الجلد، الحواف، الغرز، السحّاب، والمعدن. الريندر بيصير على كرت الشاشة. وبعدها Python بيكتب العناوين وبيعمل الموسيقى والأصوات.

المثال الجاهز هان شنطة يد جلد عنّابي، 29 ثانية:

- **الخطّاف:** الشنطة مفتوحة والأغراض طايرة حواليها: جوال، ورقة، مفاتيح، بطاقات، ومصاري.
- **السعة:** الأغراض بتفوت الشنطة وحدة وحدة، من نص الفتحة.
- **السحّاب:** بيتسكّر قدّامك بلقطة ماكرو.
- **الجيب الأمامي:** الغطا بينرفع والبطاقات بتفوت جوّا.
- **لفّة 360:** على الشنطة كلها، وكل ميزة إلها عنوان بالعربي.
- **الشعار:** ضو بيمرق عليه.
- **كرت النهاية:** فيه زر «اطلبها الآن».

وكمان بيطلّع صورة للمنتج على مكتب بدقة 8K.

> **الدليل الكامل خطوة بخطوة (PDF):** `guide-ar.pdf`. فيه التشغيل على Colab، وكيف تغيّر اللون والشعار والنصوص، وكيف تطلب من Claude منتج جديد، وحل المشاكل.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/alaahamza465-eng/product-3d-ar/blob/main/colab/product3d.ipynb)

   - **preview:** سريعة، عشان تشوف النتيجة.
   - **full:** النهائية 1920×1080.

5. لما يخلص، الفيديو بيكون بمجلد `product-3d` على Drive.

الـpreview بياخد تقريباً ساعة على كرت T4 المجاني. الـfull بياخد كم ساعة. إذا انقطعت الجلسة شغّلها مرة تانية، وبتكمّل من وين ما وقفت.

## كسكيل لـClaude (عشان تعمل منتجك أنت)

### Claude Code (الأفضل)
انسخ المجلد كله لـ:
- ماك/لينكس: `~/.claude/skills/product-3d-ar/`
- ويندوز: `%USERPROFILE%\.claude\skills\product-3d-ar\`

بعدها احكي لـClaude شي زي:

- «شغّل مثال الشنطة بجودة preview»

- «هاي صور ساعتي من 6 زوايا وقياساتها، بدي فيديو إلها بنفس القصة»

### تطبيق Claude (claude.ai / الديسكتوب)
1. نزّل ملف السكيل: **[product-3d-ar.zip](https://github.com/alaahamza465-eng/product-3d-ar/releases/latest/download/product-3d-ar.zip)**. نزّله من قسم Releases، مش من زر Code، لأنه زر Code بيغيّر اسم المجلد.
2. فعّل «Code execution and file creation» من الإعدادات.
3. روح على **Customize > Skills**، واضغط زر **+**، بعدها **Create skill**، بعدها **Upload a skill**.
4. ارفع ملف `product-3d-ar.zip` زي ما هو، بدون ما تفكّه.

> الريندر تقيل وبدّه كرت شاشة. فـClaude بيجهّز المشهد ويعدّل عليه ويفحصه، والريندر النهائي بيصير على Colab أو على جهاز فيه كرت NVIDIA.

## على جهازك (لينكس + كرت NVIDIA)

```bash
git clone https://github.com/alaahamza465-eng/product-3d-ar
cd product-3d-ar/project
python3 run_all.py --quality preview --out ~/product-film
```

بدّك Python 3.10+ و ffmpeg، وحزم: `numpy pillow scipy soundfile`. وبدّك `libraqm` عشان العربي يطلع موصول. Blender 5.2.2 بينزل لحاله.

## ليش بيطلع الفيديو نظيف

- **ما في غرض بيمرق من جوّا غرض:** في سكربت بيفحص كل إطار وكل نص إطار، وإذا لقى تلامس بين غرضين، أو بين غرض والشنطة، بيحكيلك وين وإمتى. ما بنبدأ ريندر إلا والنتيجة صفر.
- **الأغراض بتفوت بالترتيب:** كل غرض بيفوت من نص الفتحة، وإله طبقة لحاله جوّا الشنطة.
- **ما في نص مقلوب ولا انعكاس أبيض:** الورقة مطبوعة من وجه واحد، وشاشة الجوال مطفية.
